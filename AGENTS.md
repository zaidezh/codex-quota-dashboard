# Repository guardrails

- Keep this repository limited to the M1-M2-M3 quota system, its explicit local
  runtime, safe bootstrap reference, Web interface, tests, and direct
  documentation.
- Never commit live snapshots, databases, logs, paths, account identifiers,
  task titles, thread/session/response identifiers, credentials, prompts, or
  captured service responses.
- Monitoring, local fitting, and bootstrap use must remain disabled by default
  and separately explicit.
- Preserve the distinction between server observations, approximate
  explanations, strict diagnostics, alignment sensitivity, and conditional
  forecasts.
- UI changes must preserve keyboard access, visible focus, 320 px reflow,
  reduced-motion behavior, text status, and table access.
- Public product copy describes only current repository capabilities and stable
  operating contracts.
