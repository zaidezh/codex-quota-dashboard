M1–M3 数据口径

同一冻结快照区分权威观测、解释拟合与条件走势。

M1 · 证据

记录显式选择的数据源、权威额度观测、原生 token 通道、截止时间和冻结身份。

M2 · 解释

在本机活动为主要可观测解释变量的假设下，拟合近似参数、残差与时间对齐敏感范围。

M3 · 走势

把冻结的 M2 参数或显式启动参考映射为条件额度走势；用户活动变化后重新计算。

解释边界

参数不是官方费率，范围不是概率区间，走势不是额度保证；误差保留在 M2 诊断中。
